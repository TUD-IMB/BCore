# Bridge Core Ontology — Components Extension

<img align="right" src="../BCore.svg" height="200">

The **BCoreComp Ontology** extends the [Bridge Core Ontology (BCore)](https://github.com/TUD-IMB/BCore) with a precise and modular vocabulary for describing bridge components.

It focuses on the structural and functional parts that make up a bridge---everything from superstructure and substructure elements to detailed component hierarchies.

BCoreComp builds directly on BCore’s top‑level structure, ensuring that every component is consistently linked to the bridge and can be combined with other domain modules such as materials, infrastructure, media, and spatial zones.
    
Recommended namespace for BCoreComp: **`bcorecomp`**.

See all information about the **BCore Ontology Suite** over on the main [READEME.md](https://github.com/TUD-IMB/BCore).
