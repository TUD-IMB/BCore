Introduction back to ToC

The **Bridge Core Ontology (BCore)** is the central foundation of the BCore ontology suite. It defines the essential, high‑level concepts needed to describe a bridge and provides the shared semantic structure that all other modules build upon. BCore is intentionally lightweight: it establishes identity, basic structural hierarchy, and cross‑module linking, while leaving domain‑specific detail to dedicated extension ontologies. #### BCore Ontology Suite: | Module | Purpose | |--------|---------| | **BCore** | Core identity, top‑level bridge concepts, and shared linking structure. | | **[BCoreComp](/BCore/comp)** | Structural and functional bridge components. | | **[BCoreMat](/BCore/mat)** | Materials used in bridge construction. | | **[BCoreInfra](/BCore/infra)** | Bridge-related transport and utility infrastructure. | | **[BCoreZones](/BCore/zones)** | Spatial zones, geometric context, and environmental regions. | | **[BCoreMedia](/BCore/media)** | Media files, documentation, and digital assets. | #### About the BCore main ontology: The **BCore main ontology** provides the minimal conceptual model required to describe a bridge: its identity, its top‑level structure, and the relationships that connect it to more detailed domain ontologies. It ensures that all modules (components, materials, infrastructure, media, and spatial zones) integrate seamlessly into a unified representation. Main focus: - **Bridge identity and classification** - **A simple structural hierarchy** (bridge → parts → linked modules) - **Shared linking properties** across all modules - **Interoperability** for modular and extensible bridge data modeling → Thus, it is a a clean, minimal, and interoperable starting point for anyone building a comprehensive, modular semantic model of bridges.
